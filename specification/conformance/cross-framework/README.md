# Cross-framework Connector conformance

This fixture set is owned by the neutral Connector workspace. Framework
Bindings in FinClaw and Open Time Series read the same URI through the same
Connector release and compare only physical facts: Arrow/Polars schema and
values, Decimal/null/order behavior, Base/Sheet coordinate conventions,
fingerprints, and receipt facts. Framework lifecycle artifacts are explicitly
excluded from the comparison.

The multi-sheet Excel case is generated by each runner in a temporary
directory so the fixture remains portable across source distributions.
