# Rich spreadsheet readiness

The shared rich contract is qualified only where independent save/reopen
evidence exists. Local Excelize image insertion is qualified for PNG/JPEG bytes
and anchors, and the workbook session uses the same Excelize-backed sheet-mode
path as ordinary rich XLSX operations. MaybeSheet image operations remain
blocked pending authorized live disposable evidence; local binding method names
do not imply remote support.

OfficeCLI is not involved in rich XLSX authoring, export, or resave. It is an
optional document-artifact and presentation-view adapter only.

Charts, shapes, native tables, pivots, comments, validation and conditional
formatting remain blocked unless a provider-specific operation and independent
readback fixture is added.
